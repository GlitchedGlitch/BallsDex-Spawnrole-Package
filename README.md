# Spawnrole Package
## What is this?
This package adds a new command `/config spawnrole` that makes the bot ping a role when a ball spawns. Farms boutta increase
## How to install
Add this to config/extra.toml (or create the file if it doesn't exist)
```toml
# Spawnrole Package
[[ballsdex.packages]]
location = "git+https://github.com/GlitchedGlitch/BallsDex-Spawnrole-Package.git@1.2.0"
path = "spawnrole"
enabled = true
```
